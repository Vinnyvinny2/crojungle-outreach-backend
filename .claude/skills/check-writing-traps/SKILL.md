# Check-writing traps — how a check passes on a live bug

**Goal:** After reading this, Claude can write a boot check or test that fails on the live defect it names, and spot one that cannot.

New text (2026-09-02) distilled from the round notes; every rule cites the rounds that earned it, and `round-refs.md` beside this file lists more. The standing rule is PART 3 of CLAUDE.md: **a check that cannot fail is not a check**, and **instructional guards do not hold** — a rule written in a prompt or a comment is not a guard; only a mechanical check is. Every trap below is a way a mechanical check quietly became instructional.

## 1. The self-matching needle (recorded twenty-one times)

A check that greps `server.js` for a string, written as a literal, puts that string INTO `server.js` — inside the check itself — so `indexOf` finds the check's own line and passes on a build where the guarded code is gone. Two disguises: a needle assembled from a real half and an EMPTY half (one contiguous literal again, [§45](../../../docs/history/round-045.md), [§69](../../../docs/history/round-069.md), [§85](../../../docs/history/round-085.md), [§98](../../../docs/history/round-098.md)), and a comment that quotes the broken code verbatim so the needle matches the comment ([§24](../../../docs/history/round-024.md)). Rules: assemble every source needle at runtime from two or more NON-EMPTY halves (`['FIRE','CRAWL'].join('')`); search the comment-stripped copy (`selfSourceNoCommentsLF`); never put both halves on one line; and if the needle's exact text must exist for a different reason, count occurrences instead of testing presence ([§44](../../../docs/history/round-044.md)). One more shape: a needle carrying `\r\n` never matches the LF-normalised copy, and a needle with one paren too many fails a CORRECT build ([§81](../../../docs/history/round-081.md), [§91](../../../docs/history/round-091.md), [§103](../../../docs/history/round-103.md)). First recorded [§13](../../../docs/history/round-013.md); the count is in [§98](../../../docs/history/round-098.md).

## 2. A check that does not assert its call site is half a check (recorded eleven times)

A fixture supplies its own arguments, so it can prove the FUNCTION right while the CALLER passes the wrong thing, nothing, or an empty string. Four checks in one session passed with their own fix reverted for exactly this ([§25](../../../docs/history/round-025.md), [§27](../../../docs/history/round-027.md)); the stand-down flag that was a no-op in production because `!!{}` is truthy ([§29](../../../docs/history/round-029.md)); a verifier gate that read a field that does not exist while its check declared its own copy of the same field ([§46](../../../docs/history/round-046.md)); an owner-source token passed as `''` for a route's whole life ([§101](../../../docs/history/round-101.md)). Rule: beside the fixture, pin the call site with a runtime-assembled needle, or better, drive the route end to end (`servercheck.js`) so the wire itself is exercised.

## 3. NO VERDICT is not a pass (the harness that lies)

A falsification harness that cannot see a failure proves the opposite of what it appears to prove. Recorded shapes: it grepped for `⛔` while the tool printed `✗` ([§44](../../../docs/history/round-044.md)); an invalid port killed the boot before any check ran and it reported green ([§47](../../../docs/history/round-047.md), [§76](../../../docs/history/round-076.md)); a crashed boot read as green ([§59](../../../docs/history/round-059.md)); the runner read `tail`'s exit code, not the gate's ([§83](../../../docs/history/round-083.md)); a process substitution hit EPIPE and reported NO VERDICT for every revert ([§86](../../../docs/history/round-086.md)); a revert applied from the wrong directory and the restore `cp` wrote into that directory ([§70](../../../docs/history/round-070.md)); a revert helper whose third argument most reverts did not pass, so 23 of 24 did not apply ([§90](../../../docs/history/round-090.md)); a red baseline that proves reds too cheaply ([§74](../../../docs/history/round-074.md), [§93](../../../docs/history/round-093.md)). Rules: the harness keys on EXIT CODES only (as `ci-gates.sh` does); it refuses to start unless the baseline boots GREEN; it verifies every restore byte for byte; a revert that does not apply, or a boot that never prints a verdict, is reported as NO VERDICT, never as a colour.

## 4. A falsification must reproduce the original defect

Reverting "a line near the fix" and watching the check stay green proves nothing about the check. Swapping a preference order that could never matter ([§25](../../../docs/history/round-025.md)); putting a comma back while a later block recomputed the answer ([§45](../../../docs/history/round-045.md)); widening one half of a test the other half still covered ([§55](../../../docs/history/round-055.md), [§59](../../../docs/history/round-059.md)); dropping `prnewswire` while `newswire` still matched it ([§105](../../../docs/history/round-105.md)); two fixes hiding each other so reverting one leaves the other catching the fixture ([§44](../../../docs/history/round-044.md), [§95](../../../docs/history/round-095.md)). Rule: the revert restores the SHIPPED expression verbatim, and the run must print the original symptom; otherwise it is a missing case, not a pass.

## 5. A fixture that measures nothing

The fixture is arranged so the assertion holds whether or not the mechanism exists. The tiebreak winner was already preferred by another rule ([§21](../../../docs/history/round-021.md)); two pages differed in their opening words so a 40-character hash told them apart ([§23](../../../docs/history/round-023.md)); the most-mentioned bucket was declared first anyway ([§57](../../../docs/history/round-057.md)); the first marker was declared visible anyway ([§71](../../../docs/history/round-071.md)); "booked jobs" printed on nearly every sheet regardless ([§75](../../../docs/history/round-075.md)); the "filler" rows were all money rows ([§66](../../../docs/history/round-066.md)); "Marketing Manager" matches any regex with "market" in it ([§90](../../../docs/history/round-090.md)). Rule: before trusting a green fixture, ask what ELSE makes it green; then falsify by reverting the mechanism and demand red.

## 6. A message naming the wrong cause costs what a missing one costs

A log line that guesses the cause and prints the guess as an instruction sends the reader to inspect the one healthy part of the system: "check that the table exists" when RLS was refusing the write ([§16](../../../docs/history/round-016.md)); "the CREDENTIALS were refused" on an empty balance ([§85](../../../docs/history/round-085.md)); "run them one at a time" for a pacing bug ([§50](../../../docs/history/round-050.md)); "their pages do not state who owns the business" when the parser lacked the vocabulary ([§99](../../../docs/history/round-099.md)); a severity claimed at the top of the file for weeks on a routine per-domain timeout ([§3](../../../docs/history/round-003.md)). Rule: read the cause from the response (a status code, an error body), keep it per resource, clear it the moment the resource answers, and reserve the alarm for the case where every route has failed.

## 7. Two hand-kept copies of one rule

The check declares its own copy of the rule it guards, so both copies agree and both are wrong ([§46](../../../docs/history/round-046.md)); the brief summarises three of thirteen families the gate refuses ([§10](../../../docs/history/round-010.md)); a client picker holds a typed copy of the server's city list ([§32](../../../docs/history/round-032.md)); six mailbox vocabularies disagree about "recruiting" ([§97](../../../docs/history/round-097.md)). Rule: one declaration, executed by the check; the check reads the LIVE function (`String(fn)`) or the declared table, never a retyped copy.

## Also recorded

A wall-clock ruler on a shared-CPU dyno measures the dyno ([§39](../../../docs/history/round-039.md), [§55](../../../docs/history/round-055.md)); a check that hangs is quieter than one that fails, so async checks hold the verdict open ([§24](../../../docs/history/round-024.md), [§48](../../../docs/history/round-048.md)); a check that fails on a decision the owner is entitled to make is one they will delete, taking the real assertions beside it ([§28](../../../docs/history/round-028.md)); an assertion counting call sites cannot tell a production call from the boot checks' own ([§13](../../../docs/history/round-013.md)); a check whose requirement list comes from the code under test cannot fail ([§18](../../../docs/history/round-018.md), [§38](../../../docs/history/round-038.md)); a message that overstates its own severity costs exactly as much as one that understates it ([§3](../../../docs/history/round-003.md), [§24](../../../docs/history/round-024.md)).
